# 更新记录

## 1.0.1 — 2026-10-12

- 自动识别并忽略旧临时修复的超长 route-up 行，解决 OpenVPN 256 字符行长度限制导致的启动失败。
- 使用权限为 600 的临时运行配置，保留原始文件及其他自定义钩子。
- 在读取配置前切换工作目录，使相对证书和账号文件路径正常解析。
- 补充启动错误和迁移说明。

## 1.0.0 — 2026-10-12

- 新增可配置的局域网 IPv4 回程保护和推送路由过滤。
- 停止应用时清理自身规则，避免覆盖其他程序的路由表。
- 支持带空格的配置路径和相对证书路径。
- 新增中文配置说明、文件存放路径、占位示例和用户图标。
